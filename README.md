# Solar filament instance segmentation (Filament Segmentation Challenge 2026)

Box detection with two YOLO11s detectors, fused, followed by a box-seeded U-Net
mask refiner. Everything needed to reproduce our submitted predictions is in
this repository: code, trained weights and an end-to-end notebook. No
retraining is required.

## Results

| Measurement | PQ | TP | FP | FN |
|---|---:|---:|---:|---:|
| Held-out training observations (106 observations, 170 annotator passes) | **0.444** | 750 | 326 | 508 |
| Public leaderboard (submission 58270041) | **0.39** | | | |

The held-out split is by observation (seed 42, 15 %); none of the three models
saw these images during training. Scores use the organizers' Panoptic Quality
definition (IoU > 0.5), re-implemented on RLEs in `src/filament_seg/metrics.py`
and checked to give identical numbers.

## Quick start

```bash
pip install -r requirements.txt
python scripts/predict.py --test-dir data/test_images --out submission.csv
```

or open `notebooks/filament_pipeline.ipynb`, which also renders an example and,
when the training annotations are available, re-scores the held-out split.
On Kaggle, attach the competition data and this repository as a dataset; the
notebook finds both automatically.

A T4 GPU processes the 180 test observations in about 4.5 minutes; CPU works but is slow.

**Reproducibility check.** Running `notebooks/filament_pipeline.ipynb` on Kaggle
(Tesla T4, versions in `requirements.txt`) with only the official competition
data attached produced a `submission.csv` byte-identical to the submitted file
(1,108 instances on 179 observations), and re-scored the held-out split at
PQ 0.4444 (750 TP / 326 FP / 508 FN).

## Method

1. **Detection.** Two YOLO11s detectors trained on filament bounding boxes run at
   1280 px and 1920 px. Their boxes (confidence ≥ 0.05) are merged by weighted box
   fusion (IoU 0.55); a fused box scores the mean confidence over both detectors,
   so a box seen by only one detector is down-weighted.
2. **Refinement.** For each box, a square crop (1.5 × the longer box side, at least
   96 px) is resized to 512 × 512. A ResNet34 U-Net receives three channels: the
   crop, its CLAHE-enhanced copy, and a filled box seed (padded by 60 %) that marks
   which filament to segment. Probabilities are averaged over identity, horizontal
   and vertical flips, upsampled linearly to native resolution, thresholded at 0.5,
   and reduced to the largest connected component.
3. **Instance assembly.** Masks are taken from the most to the least confident
   fused box (threshold 0.32). Pixels already claimed by a stronger instance are
   removed, so instances never overlap, and remnants under 200 px are dropped.

All settings live in `src/filament_seg/config.py`.

## Training provenance

* `detector_yolo11s_1280.pt` and `refiner_unet_resnet34.pt`:
  `training/train_detector1280_and_refiner.ipynb` (YOLO11s, 40 epochs, 1280 px;
  refiner 12 epochs, 512 px crops, seed padding 0.60).
* `detector_yolo11s_1920.pt`: `training/train_detector1920.ipynb` (YOLO11s,
  60 epochs, 1920 px). That run stopped with an error after the detector was saved
  (in the unused refiner stage); the detector weights are complete.

Both use only the competition's training images and segmentation annotations,
with the same observation-level split as above. The training notebooks are
adapted from the public Kaggle notebook *"Best Score | MAGFiLO | YOLO11s Detect →
Crop U-Net"* by timgluhkikh; the inference code in `src/` is our rewrite.
